# Lessons (portable)

Conditions matter. These are **conditional** — use when similar structure exists.

## CV / selection (axis A)

1. **Lane-split Trust vs Public.** Do not share one GO/NO-GO when Public is a partial slice.  
2. **Do not Final-stack only Public heads** when multiple slots exist.  
3. **Group-aware CV** when rows share wells / patients / sites.  
4. **Multi-tier CV:** fast/small for throughput, thicker (more wells / seeds) for adopt & Final; do not make T1 the sole adopt bar.  
5. **Oracle / offline ceilings** are diagnostics, not Final proof.  
6. After reweight / loss surgery on multi-stage stacks, re-run **downstream dual** before GO.

## Methods (axis B)

1. Mid-stage improvement is fine; **shipping raw intermediates as Final** is usually a shape/risk failure mode.  
2. Residual / second-stage heads that hurt Public can still dominate Private — pre-commit a Trust narrative.  
3. When top solutions later show multi-path / ensemble density, treat late single-path gambling as risky (retrospective note).

## Ops (axis C)

1. **Static checks before GPU.**  
2. **Ban abstract repeats** after NO-GO streaks.  
3. Archive **submitted kernels** early; wipe machines after private + public portfolios exist.  
4. Post-comp: verify Final with Private CSV/API — write which slot won and why.
