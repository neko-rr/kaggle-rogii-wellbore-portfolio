# Approach

One coherent story for a residual **Trust** Final surface (666) and a **Public**-lane surface (farvol). This is not an inventory of every experiment ID.

## Design goals

1. Respect well / group structure (avoid row-KFold theatre).  
2. Keep a shippable **Trust** path under a held-out / hard well proxy.  
3. Allow a separate **Public** chase surface for Final diversity.  
4. Gate residual mid-stage material — improve intermediates, but do not dump raw mid faces as the Final story without policy.

## Production path (conceptual)

1. **Geometry + logs** → path / matching estimate against typewells.  
2. **Base TVT surface** from tip-style / mid-stage pipeline (inherited public ruler ideas refined under local CV).  
3. **Residual head (Trust)**  
   - Mid surface + residual blend with **α ≈ 0.35** (666).  
   - Accepted on Trust / dual style checks even when Public looked worse than pure tip.  
4. **Public lane**  
   - Thin tip×blend **farvol** profile (0.95 / 0.05 style) for strong Public RMSE.  
   - Intentionally **not** the sole Final private bet.  
5. **Submission**  
   - Slot 1 = Trust residual 666 · Slot 2 = farvol.  
   - Human confirmation only; agent loop does not submit.

## What we stopped doing (signal of maturity)

- Treating Public wobble (±≈ noise) as Trust kill switches.  
- Promoting raw intermediate artifacts to Final without gates.  
- Retrain / loss-weight ladders that failed dual residual acceptance (all NO-GO before deadline — correct stop).
