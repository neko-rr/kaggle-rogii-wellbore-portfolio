## B9 — Soft-Preserve Ranker

### 狙い

tip soft 粒子／多seed の **候補バンクは提出しない**。  
学習した選択・加重で **新FINAL** を作り、soft→selector 崩壊を避ける。  
門番 PASS 時のみ枠2候補。

### やらない（Explicit）

- tip 温度・BH・難井パック・形直し（F025–**F040**）  
- soft / before_hedge / learned 中間面の提出昇格（**F015**）  
- soft RMSE を採択根拠にする（**F023**）  
- Wave-29 S1a/S1b の薄い再実行（**F041**）  
- Public 井単位座標探索（Hierarch同型 · Stop）  
- C/D ブレンド比率スイープ  

### パイプライン（概念）

```text
[A] tip soft 候補バンク（粒子・多seed · 提出禁止）
      ↓
[B] well-GroupKFold で選択/加重を学習（GPU）
      ↓
[C] 新 FINAL 面のみ出力
      ↓
門番 → PASS なら E2E Private kernel → 枠2候補
```

### 門番（枠2昇格 · 1サイクル即死）

1. hard20（または tip-cv 同型）で **CF超え**  
2. tip FINAL（SUB-14 面）との pearson **≪ 0.99**（目標 &lt; 0.95）  
3. sample 井の壊滅なし  
4. tip FINAL tip-cv より **≥ +0.30**（または明確非悪化＋別面性を同時満たす）  
5. Code Comp E2E（Internet OFF · 自 kernel · F005）  

**hard20 本実験1回で未達 → Wave-30 CLOSED · F041 追記 · Active=OPS-FINAL2のみ。**
